Does Retinex preprocessing
help PCB component detection?

Bilateral and variational Retinex with YOLO26 on a 4-class dataset (Capacitor, Connector, Electrolytic Capacitor, IC) — evaluated across multiple seeds.

Edgar Tadevosyan

ProblemDense, small components on high-resolution boards

4
classes
1280px
training resolution
42
test images evaluated
≈3,800
capacitors in test set

Hypothesis

Removing illumination (shading, glare) and emphasising edges should help detectors on small, low-contrast parts — especially capacitors.

Protocol

YOLO26s, 100 epochs, batch 8, max_det=1000, conf 0.001, same cleaned dataset and test split for every run. 3 seeds per main config.

Method 1Bilateral Retinex + edge fusion

Edge-preserving illumination estimate, reflectance recovered per image, fused back with the original.

RGB image
→
V = max(R,G,B)
→
bilateral filter → illumination L
→
reflectance R = log V − log L
→
fuse with original (α, β)
α = 0.30 · β = 0.10  |  fast: ≈0.17 s / image on CPU at 1280px (measured)

Output is a normal 3-channel image, so any YOLO model trains on it unchanged.

Method 2Variational Retinex with channel-wise fusion

Weighted variational model (Fu et al., CVPR 2016) solving for reflectance R and illumination L jointly.

Fu et al. (CVPR 2016) Weighted Variational Optimization
minr, l   ‖r + l − s‖22  +  c1 ‖er · ∇r‖1  +  c2 ‖el · ∇l‖22
Physical Model: S = R · L  (s = log S, r = log R, l = log L)  |  Enhanced: Senh = R · L1/γ  (γ = 2.2)

Per-channel

reflection_c + channel_c for R, G, B, then recombined.

Cost

≈3.3 s / image on CPU; ≈46 img/s on H100 in the dataset script (measured).

Caveat

On the demo image the stopping rule was not met in 15 iterations (ε_r=0.038).

Important caveat

No ensemble of the raw-image seeds has been evaluated yet, so we cannot attribute this gain to Retinex rather than to ensembling itself. That control is prepared (train_base_seed_ensemble.sh) and is the next experiment.

ConclusionsWhat we can and cannot claim

Supported

  • Single-run comparisons are unreliable: baseline varies by 3.4 points across seeds.
  • Bilateral Retinex ≈ baseline (+0.0065, within noise).
  • Copy-paste, P2 head and lower hsv_v gave no gain in these single runs.
  • Multi-seed WBF ensembling reaches 0.619 mAP50.

Not shown

  • That Retinex improves small-class detection.
  • That the ensemble gain comes from Retinex.
  • Any benefit of the variational method (it scored lower).
  • Effects on boards with strong shadows/glare — test boards are evenly lit.

Next stepsPlanned work
